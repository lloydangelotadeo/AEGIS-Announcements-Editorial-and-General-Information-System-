# AEGIS

Announcements, Editorial and General Information System

An interactive digital information kiosk designed and currently
deployed at DENR - PENRO, Nueva Vizcaya, Philippines.

## Features

- Announcements management
- Editorial management
- Events
- Digital posters
- Weather information
- Kiosk display mode
- Administrative management
- Responsive interface
- REST API backend
- SQLite persistence
